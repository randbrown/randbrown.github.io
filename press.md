## Bio

**Short** — Randy Brown is a Knoxville pedal-steel player, guitarist, and software developer working across ambient live code (voidstar), pedal steel in the band nightjar, metal (Dysmorphic Demiurge), and solo records as randbrown.
{: .epk-bio}

**Medium** — Randy Brown is a Knoxville, Tennessee musician and software developer whose work runs from heavy riffs to long, quiet drones. As voidstar, Randy routes pedal steel through live-coded patterns and audio-reactive visuals built from scratch for the browser. Randy also plays pedal steel in the band nightjar, is in the metal band Dysmorphic Demiurge, and releases solo music as randbrown, ranging from alternative rock to chillhop and electronic. The day job is code, too — which is how a steel guitar ended up plugged into a programming language.
{: .epk-bio}

## Projects

### voidstar — *Randy Brown's voidstar*
![voidstar](/assets/pics/thumbs/rv.jpg){: .epk-thumb}
Ambient, improvised pedal steel run through live code (Strudel), with audio-reactive, pose-tracked visuals from **qualia** — an open-source performance instrument that runs in a browser. Solo, or as a father/son duo with Cade Brown.
